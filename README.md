# Lumina Salon & Beauty

Production-oriented Next.js salon website with an immersive, image-led visual system.

## Included
- Responsive desktop/mobile navigation with accessible hamburger menu
- Image-led hero sections, service cards, gallery masonry, team portraits and service detail pages
- Premium editorial visual language: warm neutrals, blush accents, serif display typography and glass surfaces
- Responsive layouts built with Tailwind CSS v4
- Next.js Image optimization for Unsplash-hosted imagery
- SEO metadata, Open Graph defaults and accessible skip navigation
- Existing booking/contact flows and API routes retained
- Reduced-motion support for accessibility

## Run locally
```bash
npm install
npm run dev
```

For production:
```bash
npm run build
npm run start
```

## Images
The current demo uses curated Unsplash image URLs so the project remains lightweight and easy to replace. For launch, replace these with owned/licensed brand photography or a connected CMS/image CDN. The remote hostname is already configured in `next.config.ts`.

## Brand details
The demo copy uses Lumina Salon & Beauty, Bangalore, with the existing sample contact details. Replace the address, phone, email, social links and pricing before launch.
